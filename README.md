# Ora — vydané verze

Tady bydlí hotové buildy **Ory**, aplikace pro macOS. Zdrojové kódy tu nejsou —
tenhle repozitář slouží jen k tomu, aby si nainstalovaná Ora uměla sama stáhnout
novější verzi.

## První instalace

1. Stáhni si `.dmg` z [posledního vydání](../../releases/latest)
2. Otevři ho a přetáhni Oru do složky Aplikace
3. Při **prvním** spuštění na ni klikni pravým tlačítkem → Otevřít

Třetí krok je potřeba proto, že Ora není notarizovaná u Applu. Stačí jednou.
Další aktualizace si Ora stahuje sama a tímhle dialogem už neprochází.

## Aktualizace

Ora se po spuštění tiše podívá, jestli tu není novější verze. Když je, rozsvítí
se tečka u ozubeného kolečka v levé liště. Vyvolat kontrolu ručně jde
v **Nastavení → Obecné → Aktualizace**.

Každý balíček je podepsaný; podvrženou aktualizaci Ora odmítne rozbalit.

## Podporované Macy

Apple Silicon (arm64), macOS 13 a novější.
